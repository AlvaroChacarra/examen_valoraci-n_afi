## Prioridad de la evidencia

El enunciado define el encargo. Los documentos teóricos definen los modelos de clase. Una solución Excel muestra una implementación concreta y puede tener parámetros particulares o defectos. Las fichas explican esa implementación; no alteran el contrato. El OCR es una ayuda de recuperación, no autoridad para un signo o exponente dudoso.
